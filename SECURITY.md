# Security Policy

This repository contains research or prototype code unless the README explicitly states otherwise. Do not assume a production release or guaranteed response-time SLA.

Do not publish credentials, private keys, access tokens, personal data, or exploitable unpatched details in public issues. Use GitHub private vulnerability reporting for this repository if enabled. Otherwise follow the verified private reporting guidance in the [foundation security policy](https://github.com/Deku-Foundation/Deku-Foundation.github.io/blob/main/SECURITY.md).

Include the affected revision, impact, reproduction steps, and mitigations where safe. Do not access or modify systems or data that are not yours. A successful test suite is not a security audit.
