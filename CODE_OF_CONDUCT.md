# Code of Conduct

Participation in this repository is subject to the [Deku Foundation Code of Conduct](https://github.com/Deku-Foundation/Deku-Foundation.github.io/blob/main/CODE_OF_CONDUCT.md).

Be respectful, critique code and ideas rather than people, respect privacy, and keep technical discussions constructive. Harassment, threats, discrimination, doxxing, and sustained personal attacks are not acceptable. Report concerns privately to maintainers through a verified channel; do not publish personal information in issues.
